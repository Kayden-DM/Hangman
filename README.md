Simple Hangman
A simple command-line hangman game built with Python that gives you 6 lives to guess a word. It uses .len to check the word length and 'for i' loops to check where each guessed letter appears in the word.

Features
Uses .len

Uses 'for i' to check where the letter is in the word

Gives you 6 lives
